# 5.0.1 手谱转换实验室修正

自动读取 MP4 原始帧率；模板确认后寻找十个有效头部，排除离群值并显示平均运动时间、等效流速与波动。帧率和流速均可手动覆盖。

已确认的蓝色、黄色／暖色多押和尾部模板进入独立保留区，不受重匹配或时刻切换影响。候选截图从识别当帧复制，避免重取帧产生空图或错位。每类最多四个。

全片平均背景抑制静态干扰；径向颜色轮廓容忍正常残影，允许低 FPS 下两帧有效运动证据。推断的蓝色长条尾、同拍残影合并和少见分拍保守降分待审。

在 min(55ms,1.5 源帧) 内优先考虑 1/2、1/4、1/8 拍；1/3、1/6、1/12、1/16 采用更保守先验，密集段或低 BPM 放宽 1/16。保留原始时刻与吸附量，校准页可恢复。源帧顺序解码以媒体就绪事件为准，名义时间额外降分。

音频 BPM 候选、首音符对齐与低置信度音符仍须人工确认。输出数量不是正确物量或准确率；必须检查完整视频中的漏识别和长条配对。测试媒体不随源码或站点发布。详细回归结果见 testing.md。
