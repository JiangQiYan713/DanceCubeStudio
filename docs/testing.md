# 自动检查与验收边界

## 执行方式

所有检查在仓库根目录执行。无需构建网站。纯逻辑测试直接用 Node，DOM 测试需要 jsdom、fake-indexeddb 与 @napi-rs/canvas。可将它们安装在仓库外，通过 DC_JSDOM、DC_FAKE_IDB、DC_CANVAS 指定模块路径；Canvas 也支持运行时依赖目录。PowerShell 验证可设置 PWSH。

```sh
for test in tests/*.cjs; do node "$test" || exit 1; done
```

完整检查包含 installer.cjs；没有 PowerShell 时先为它准备可用运行时。不要为方便让失败自动忽略。语法检查可对 dist/*.js 运行 node --check。

## 核心规则覆盖

core、timing、analysis、skin 检查拍数反算、变 BPM、Offset、FFT、生成密度、假键、镜像、图集和 MUI。格式检查将真实示例与署名保留的 MC2TXT 参考输出比较。TXT 两位小数量化和纯 TXT 不唯一恢复属于明确边界。

units382 检查固定 0.2 秒模型、头部与持续判定、变 BPM、Offset / rate / FPS 不改变总数、滑条整链堆叠、大整数与跨区几何。默认 17 级总物量为 1900；历史实验设置不能恢复旧拟合。

beat40 检查四种音效、文件起音、预卷四事件、头部去重、滑条续段排除、音乐倍速与两级延迟公式、定时器调度和取消。app40 检查 -16 拍起播、音乐延迟启动、负拍保护、共享秀谱分析 / 位置 / 物量、计划懒加载与持久化。settings40 检查自定义音效、条件字段、配置媒体迁移与缺失回退。

## 账号与资源

账号检查使用脱敏结构与离线 fixtures。验证真实等级与档位分离、0 级、共享歌曲 ID、明确搜索类型、限流取消、资源 URL 及原生 ZIP 保真。不记录真实 token、手机号、个人响应，不自动购买、装备、换绑或上传。

实际官方接口、浏览器 CORS、登录回跳与下架资源权限必须另行只读联调。函数单测通过不表示计划页中的已知问题已解决。

## UI、音频和设备

离线 DOM / Canvas 检查覆盖设置点击、模板 / 导出入口、秀谱编辑与类型确认、缓存和物量显示。模拟 AudioContext 验证 start/stop 的时间参数与队列，不模拟实际声卡。

真实设备仍需检查：首个预卷声到音符头的同步、蓝牙与有线输出、主线程负载、暂停后无残响、60 / 120 Hz 屏幕、手机触控、长页面和小视口、Malody 回导、舞立方机台以及 Windows 启动器。受策略限制无法运行浏览器 QA 时，明确报告该限制，不能用 DOM 测试宣称完成硬件验收。


## 5.0 手谱转换实验室

- `node tests/rec50.cjs`：BPM 秒数节点映射、首音符 0 拍、跨轨一帧内合押、长条头尾置信度、5/12 等分拍标记、禁止未校准去标、MC extra 回读、导入元数据规范化、静态干扰拒绝。
- `node tests/rec50-vision.cjs`：从内置 main.png / atlas 提取真实贴图，在固定机位合成六边形场景里检查五个音符头与一个尾部、轨道、到线误差、长条配对与几何拟合。需要 @napi-rs/canvas，可用 DC_CANVAS 指定包目录。
- `node tests/app50.cjs`：需要 DC_JSDOM、DC_FAKE_IDB、DC_CANVAS；验证入口 / 取消无修改、REC 导入后的待审状态、逐个起尾修改、去标签、撤销重做及自动保存。视频解码由真实浏览器单独验证，不能由 jsdom 代替。

真实浏览器验证使用独立 120 BPM 合成音频和 60 FPS、6 秒无声 H.264 视频，不包含真实账号或用户录像。该测试范围不证明实体机台手谱识别精度。测试视频与原始帧保留在临时 QA 目录，不发布到站点。

最终浏览器样本结果：自动显示 3 个独立视频候选，测得约 120.005 BPM；人工确认 120 BPM / 首音符音频 0.5 秒后生成 5 个音符（含 1 条长按）。5 项保守低分均可逐一校准，之后可移除 REC。实际已验证新建歌曲和已有歌曲追加难度两条路径；额外测试脚本覆盖取消、回读、撤销 / 重做。尚未以真实机台手谱录像测量精确率 / 召回率。

## 5.0.1 实拍与残影回归

- rec501.cjs：MP4 视频轨 FPS、浏览器呈现估计、十音符均值与离群值、常见分拍先验／高证据三分拍、原始时刻、残影合并、两帧轨迹、蓝／黄色残影、静态背景抑制及识别当帧截图。
- rec501-video.cjs：源帧索引顺序、seeked 就绪、名义时间标记、提前结束、取消及事件清理。
- rec50.cjs、rec50-vision.cjs、app50.cjs 继续通过；app50 另检查自动 FPS 默认为空、模板前不要求流速、原始时刻恢复与 REC 去标门槛。全部 JavaScript 语法检查通过。

整段离线回归使用用户提供的 Kerberos MP4 与 MP3。MP4 原始索引为 30 FPS / 3898 样本；FFmpeg 按 30 FPS 重采样读取 3899 帧（末尾补齐不构成新音符）。默认模板输出 751 音符、54 长按、247 黄色／多押、490 项待审，十音符平均运动时间 0.484454 秒，变异系数 1.62%。这些是识别输出，不是原谱真值或准确率。BPM=197 为人工确认测试值，首音符音频位置约 8.62187 秒，仍需试听复核。完整草稿 ZIP 字节与元数据校验通过，包含音频，不含视频。

网页端到端采用同一实拍 9～19 秒片段，缩为 480×270（与分析画面一致）供回归。自动 FPS=30，蓝／黄模板在全片重匹配后保留；错误尾部候选未确认，以新的独立蓝色样本补足三个。自动十音符均值 0.4821 秒、等效流速 5.186、波动 1.9%；BPM 候选约 197.0031 并显示低匹配度警告。人工确认 197 BPM / 音频 8.620 秒后生成 61 音符、1 长按、30 项待审，自动加入传奇19·REC。网页已生成原生 ZIP 下载入口；当前自动化浏览器对 blob 下载未返回下载事件，实际接收文件未在该浏览器中验证，ZIP 内容由本地检查补充。

完整 751 音符草稿已在网页回导：751 / 54 / 490 计数一致，前 100 项提供恢复原始时刻，存在待审项时去标按钮禁用。浏览器捕获的控制台错误仅来自扩展元数据上报。媒体、截图、QA 依赖和中间谱面不进入源码或部署。

## 5.0.3 连续性与本地取帧

rec503.cjs 覆盖平行条体与离散圆形纵连、真实条体结束配对、长条中的碎片归并、缺尾部时红框估算尾拍、后续纵连保留、150ms 以上短时失联后的同编号重关联、预测不增加观测或事件。rec503-seek.cjs 覆盖解码器卡住时一次回退重试、重试次数有界、错误诊断与事件清理；rec501-video.cjs 加入 seeked 事件丢失但实际已就绪的情况。rec50 / rec501 / rec502 与 app50 回归通过。

另使用 Kerberos 原始实拍全片进行默认模板离线回归，读取 3899 个重采样帧。已检查真实条体样本，并恢复 14.327 秒（轨5）和 16.929 秒（轨2）附近的长条候选；缺少独立尾轨迹的尾拍明确标记为估算、最多35分，不能作为已校准真值。没有逐音符标注，数量变化不能证明精确率／召回率提高。辅助补帧仅预测轨迹框，未生成或重编码新视频画面，虚拟框不作为条体证据。

## 6.0 经典 6K 试玩

`node tests/play60.cjs` 验证默认 / 专业 / 自定义的毫秒边界，±100ms 消耗与提前忽略，按 BPM 积分的总物量，假键排除、练习长条裁切，5% / 60% / 80% 边界、提前覆盖超过 100%、接回、多 owner 并集以及快速滑入路径与计分守恒。

`node tests/app60.cjs` 使用与 app50 相同的 DOM / Canvas 依赖，检查入口、选曲、练习段物量、非法窗口 / 区间 / 重复键位、页面全屏回退、资源就绪、完整单点 / 长条计分、编辑器热键隔离、暂停后输入释放 / 一秒续播、PNG Canvas / 全部 CSV、重玩归零和返回无谱面修改。AudioContext 为时间可控 fixture，不输出真实声音。

真实设备还应验证：手机六指和滑动跨边界、多个输入占同轨、系统全屏拒绝 / 退出、后台切换、触控 / 音频延迟校准、蓝牙输出、长条透明度、默认与专业边界手感，以及 PNG / CSV 实际文件接收。试玩规则属于本地实验室，不按机台认证。
