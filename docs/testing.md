# 自动检查与验收边界

## 执行方式

所有检查在仓库根目录执行。无需构建网站。纯逻辑测试直接用 Node，DOM 测试需要 jsdom、fake-indexeddb 与 @napi-rs/canvas。可将它们安装在仓库外，通过 DC_JSDOM、DC_FAKE_IDB、DC_CANVAS 指定模块路径；Canvas 也支持运行时依赖目录。PowerShell 验证可设置 PWSH。

```sh
for test in tests/*.cjs; do node "$test" || exit 1; done
```

完整检查包含 installer.cjs；没有 PowerShell 时先为它准备可用运行时。不要为方便让失败自动忽略。语法检查可对 dist/*.js 运行 node --check。

## 核心规则覆盖

core、timing、analysis、skin 检查拍数反算、变 BPM、Offset、FFT、生成密度、假键、镜像、图集和 MUI。格式检查将真实示例与署名保留的 MC2TXT 参考输出比较。TXT 两位小数量化和纯 TXT 不唯一恢复属于明确边界。

units382 检查固定 0.2 秒模型、头部与持续判定、变 BPM、Offset / rate / FPS 不改变总数、滑条整链堆叠、大整数与跨区几何。默认 17 级总物量为 1900；历史实验设置不能恢复旧拟合。

beat40 检查四种音效、文件起音、预卷四事件、头部去重、滑条续段排除、音乐倍速与两级延迟公式、定时器调度和取消。app40 检查 -8 拍起播、音乐延迟启动、负拍保护、共享秀谱分析 / 位置 / 物量、计划懒加载与持久化。settings40 检查自定义音效、条件字段、配置媒体迁移与缺失回退。

## 账号与资源

账号检查使用脱敏结构与离线 fixtures。验证真实等级与档位分离、0 级、共享歌曲 ID、明确搜索类型、限流取消、资源 URL 及原生 ZIP 保真。不记录真实 token、手机号、个人响应，不自动购买、装备、换绑或上传。

实际官方接口、浏览器 CORS、登录回跳与下架资源权限必须另行只读联调。函数单测通过不表示计划页中的已知问题已解决。

## UI、音频和设备

离线 DOM / Canvas 检查覆盖设置点击、模板 / 导出入口、秀谱编辑与类型确认、缓存和物量显示。模拟 AudioContext 验证 start/stop 的时间参数与队列，不模拟实际声卡。

真实设备仍需检查：首个预卷声到音符头的同步、蓝牙与有线输出、主线程负载、暂停后无残响、60 / 120 Hz 屏幕、手机触控、长页面和小视口、Malody 回导、舞立方机台以及 Windows 启动器。受策略限制无法运行浏览器 QA 时，明确报告该限制，不能用 DOM 测试宣称完成硬件验收。
