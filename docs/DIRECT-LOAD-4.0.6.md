# 4.0.6 指定 ID 兼容载入

商店指定歌曲 ID 查询继续使用官方 GetGoodsInfo。优先接受匹配 MusicID 的正常商品；缺少 GoodsID 等商品字段时，检查匹配 MusicID、官方谱面文件地址、有效 BPM 和首音符时间，符合条件可按 ID 尝试载入。不会补造文件地址、替换不同的返回 ID 或绕过接口权限。

ID 查询忽略残留曲名/谱师等筛选。状态明确关闭时标记已下架，其余兼容记录只显示商品信息/上架状态未确认。没有结果与网络/鉴权失败分开显示。详情重新读取后再次验证 ID 和可加载性；后续沿用现有文件读取、权限、大小、实际等级及必要谱面校验。

测试：tests/direct406.cjs 验证 ID 不匹配、缺少必要参数、不可信资源域名拒绝，未知和下架状态区分，以及缺少 GoodsID 时实际组装可读 ZIP。package402.cjs 与 app40.cjs 回归通过。
