# 经典 6K 谱面试玩实验室 · 6.0.0

本次大版本增加工作台“谱面试玩”，并将“手谱转换”实验室标注改为“开发中…”。面向玩家的完整操作与判定表在 dist/README.md；实现与数据生命周期在 dist/DEVELOPMENT.md / dist/LEGAL.md。

## 规则决议

需求中的两档单点判定均名为 Perfect，均按每物量 100 分，明细分别标记内档 / 外档。专业模式两个上界都为 20ms，外档区间为空。Great、Good、Miss 的专业上界分别为 40、60、60ms；未操作视觉过期仍为 +100ms。自定义四个上界必须严格递增，范围 1～99ms。

长条提前 100ms 开始计入覆盖，可接回；多键 / 多指同轨取时间并集。严格超过 80% 才是 Perfect，恰好 80% 是 Great，恰好 60% 是 Great，恰好 5% 是 Good。积分先使用 BPMList / Offset 转成秒，长条物量不依赖渲染帧率。局部练习按半开区间裁切，跨区间的长条重新计算时长与物量，不累计区间外的提前按住。

当前没有收到可访问的键位形状附件，默认采用经典六个方向上的六边形键位；每轨可调距离 / 大小。皮肤仍按当前网页皮肤显示；试玩几何围绕判定框适配屏幕，不改写皮肤配置。

## 数据与实现

play-core.js 为纯计分 / 几何模块，play-lab.js 为设置、资源、输入、渲染、暂停与结果流程，play.css 为独立响应式界面。所有游戏状态与结果在内存，用户主动下载 PNG / CSV 才写出文件；不发送官方成绩、不修改原谱面或 REC 审核状态。

选择阶段解码音乐读取时长；开始阶段申请系统全屏、复用音频并预热皮肤 / 判定贴图、曲绘和谱面索引。拒绝系统全屏时采用页面全屏并提示。无应用帧率上限，实际仍受屏幕与浏览器限制。开始两秒准备，暂停恢复一秒准备；失焦、隐藏、音频中断及退出全屏会暂停和释放输入。

- play60.cjs：默认 / 专业 / 自定义边界、提前 / 漏击、假键排除、BPM / 裁切物量、接回与多 owner 并集、快滑穿入、得分守恒。
- app60.cjs：完整应用的入口、选曲、区间 / 热键 / 判定校验、资源加载、键盘计分、长条接回、编辑器隔离、暂停恢复、成绩 / CSV、重玩与释放。
- 沿用 app40 / app50 等回归检查编辑、REC 与原有预览。真实浏览器 QA 和硬件验证记录见 docs/testing.md。

逻辑和模拟音频测试不能证明手机多指上限、设备端到端延迟或官方机台一致性；最终手感应在目标设备校准。最大 Combo 按音符最终判定顺序增加物量，长条在尾部整体结算，不模拟机台的逐 tick Combo。
