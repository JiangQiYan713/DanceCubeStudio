# 5.0.0 手谱转换实验室发布说明

新增“手谱转换”入口，与自动写谱并列。完整流程和参数见 dist/README.md；实现和数据字段见 dist/DEVELOPMENT.md；本地处理 / 导出范围见 dist/LEGAL.md。

本次为网站大版本。已有歌曲 / 难度 / 设置保持兼容，不自动迁移或覆盖原谱。Windows / Android 安装器二进制没有在此版本重建；它们原有的网页资源更新机制继续独立工作。

识别基于内置皮肤的本地模板与径向运动轨迹，不是通用视觉模型。固定机位经典 6Key、无 SV、清晰近正视是当前适用范围。首音符音频时刻必须人工确认。所有低置信度红框需逐个复核，标签清除不代表没有漏音符。无可用轨迹时不会创建半成品难度，可返回校准重试。

验证范围：纯数学 / 元数据 / 运动单测、内置真实贴图合成画面、完整编辑器的导入 / 校准 / 去标 / 撤销保存回归，以及独立合成 MP4 + 音频的浏览器链路。尚无用户实拍标注数据，不能承诺具体正确率。

浏览器验收记录：使用 6 秒无声 H.264、60 FPS 合成视频与独立 120 BPM 音频，最终版生成 5 个音符（含 1 条长按），成功追加到已有歌曲并复用音频；原难度保留。该压缩样本的 5 项均保守标为低置信度，逐个修正起尾拍后可清除 REC 标签。自动 BPM 候选约 120.005，人工确认为 120；首音符音频时刻人工设为 0.5 秒。此记录只证明该合成样本的功能链路，不代表实拍正确率或免校准能力。
