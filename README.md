# DanceCube Studio

经典六键与秀谱同屏制谱工具，应用版本为 6.1.0。编辑、频谱分析、BPM / Offset 测量、自动写谱、手谱视频转换、谱面试玩及节拍音在浏览器本地运行，无需外部 AI 接口。账号中心按需连接舞立方官方服务。

## 使用入口

- `dist/README.md`：面向玩家的使用指南。
- `dist/DEVELOPMENT.md`：数据格式、时间计算、模块职责与维护方式。
- `dist/LEGAL.md`：第三方关系、资料来源、存储与连接说明。
- `dist/plan.MD`：已知问题与待规划功能，仅作展示。
- `installer/README.md`：Windows 本地安装器的运行与构建。
- `SOURCE-NOTICE.md`：源码与资源权利说明。

网页顶部“指南 / 开发 / 计划 / 法律”分别按点击读取外部 Markdown，不在启动时预加载。

## 本地运行

网站为无需构建的静态 HTML / CSS / JavaScript。将 `dist/` 作为 HTTP 服务根目录，例如：

```sh
python -m http.server 8964 --directory dist
```

在浏览器打开 `http://localhost:8964/`。请使用 HTTP 服务，直接双击 HTML 无法可靠使用 Worker、资源读取与持久存储。换域名、端口或浏览器前先导出 ZIP、配方和网页设置。

## 关键行为

经典六键、秀谱外框 / 内框以及经典试玩共用流速定义：`设定值 = 3秒 / 从出现至经过判定点的用时`，即基准飞行时长 `T = 3 / 设定值` 秒，包含出现时从小到大的孵化阶段。例如流速 6 对应 0.5 秒、8 对应 0.375 秒。基准以原速播放、无 Effect 变速为准；BPMList / Effect 和播放倍速仍按既有时间轴工作。升级保留已存的流速数值，不自动乘倍率。

网站背景直接由客户端读取设置中的外部 URL，默认地址为 `http://puzzyhxme.seallom.fun:9443/wallpaper/002/`；源码不再附带 `dist/assets/web-background/index.html`。HTTPS 站点按混合内容规则尝试 HTTPS，远端不支持或禁止嵌入时背景可能不显示，可在设置中换 URL、关闭或导入自己的本地素材。

谱面以 BPMList 和 Offset 映射音乐时间。经典轨道为 123654，秀谱增加 ABCDEF，可选择分离滑条为 18 轨。编辑器保留第 -16 拍至 0 拍的只读预卷，重新播放从 -16 拍开始。

物量采用固定 0.2 秒间隔：单点为 1；长条和整根滑条为 `1 + floor(时长秒数 / 0.2)`，滑条乘堆叠数；假键为 0。Combo 随音乐时间累计物量。编辑预览的目标帧率为 60 / 120 FPS；独立试玩不设帧率上限，实际受浏览器与屏幕刷新率限制。节拍音使用 Web Audio 时间调度，可上传音效并分别校准文件起音及设备延迟。

原生 ZIP 保留假键、秀谱元素、BPMList 与 Effect。MCZ 为经典投影，存在假键或秀谱内容时需确认兼容性损失。TXTpack 包含机台 TXT 和回读元数据；秀谱默认不输出 SV。

## 手谱转换实验室（开发中…）

“手谱转换”位于自动写谱旁。选择已有歌曲或填写新歌名，上传 / 沿用歌曲音频并设置难度，再选择本地经典 6Key 手谱视频。流程为全片粗扫 → 校准中心 / 六个判定点 / 三个模板 → 自动帧率与十音符平均流速 → 本地测算并人工确认 BPMList 和首音符音频时刻 → 全片逐帧抄谱 → REC 校准。

视频可无声，不上传、不缓存进歌曲库、不写入导出包；音频与新难度在完成后按原有规则保存在本机。低于 60 的启发式置信度音符显示红框，逐一修正或删除误识别后才能移除 REC 标签。首个识别音符为 [0,0,n]，与歌曲音频的对应时刻必须人工核对。无声视频不能自动证明音频同步位置。

仅支持固定机位、接近正视、与内置皮肤相近的经典六键，无 SV / 停流 / 倒流。算法为本地图像模板与运动轨迹启发式，不能保证实拍的识别率，也无法仅靠红框找出漏识别的音符；须对照完整视频审谱。详情见 dist/README.md、dist/DEVELOPMENT.md 和 docs/REC-5.0.1.md。

## 谱面试玩实验室

顶部“谱面试玩”可选择本机歌曲中的经典 6K 难度，进行全时长游玩或按音频秒数截取练习区间。支持六边形触控键位、滑入触发、默认 1～6 / 小键盘热键、每键独立距离 / 大小、视觉流速、亮度、音量和输入延迟校准。选择完成后申请全屏，显示资源加载进度并以原速音乐开始两秒准备。

计分可选默认、专业或自定义；两档 Perfect 均为 100 分，Great 86、Good 50、Miss 0。每次按下优先绑定本轨最早可判定的音符，持续按住不会激活下一根长条。长条窗口为头前至尾后各 100ms，比例为（有效累计按住秒数＋仅一次 0.2 秒补偿）÷ 原长条时长；未激活不给补偿，松手时比例超过 80% 即完成 Perfect。满分 = 本次区间物量 × 100；长条物量仍为 1 + floor(时长秒数 / 0.2)，跨练习边界时先裁切。假键不计分。结束后可打开 / 下载成绩图，查看 D～SSS 等第、AP / FC，以及按需加载的双纵轴柱状图；图表支持缩放、平移和点选坐标，可导出完整 CSV。全局大小 / 距离开关锁定逐轨项，默认大小 2、距离 0.9；重叠布局不可开始，按键反馈默认 0%，独立于皮肤特效。

试玩不修改谱面，不提交官方成绩。设置只在本页会话内记忆，成绩在退出试玩时释放。手感依赖设备延迟，触控与多指上限仍须在实际设备验证。完整规则和使用说明见 `dist/README.md`、实现边界见 `docs/PLAYTEST-6.1.0.md`。
