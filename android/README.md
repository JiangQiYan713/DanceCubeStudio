# DanceCube Studio Android 1.0.1-preview

实验版独立 Android WebView 应用，Android 7.0（API 24）及以上，需要支持现代 JavaScript 的 Android System WebView。不是 PWA，也不依赖用户在外部浏览器中打开本地网站。

## 使用

安装 APK，首次启动自动从公开仓库 https://github.com/JiangQiYan713/DanceCubeStudio 的默认分支下载整个仓库 ZIP，并将 dist 内容存放到应用私有目录。仓库根目录必须有完整的 dist/index.html、app.js、其他脚本和素材。下载使用 HTTPS，失败显示原因及重试选项。下载到临时目录，验证入口后替换本地副本，失败保留旧版。首次运行必须可访问 GitHub API 及其 ZIP 下载服务。没有打包网站素材，APK 很小属于正常情况。

之后使用本地副本启动，不在播放期间检查或下载更新。返回键打开“继续编辑 / 更新站点 / 退出”菜单；更新前先导出备份。在线账号和在线资源仍需网络，受服务接口及 CORS 限制，尚未实测。

应用只在回环地址 127.0.0.1:18964 提供静态文件，退出关闭服务；不开放局域网访问。固定来源保留 IndexedDB 和 localStorage。不要自行更换端口，否则会使用不同的存储空间。端口被其他进程占用会报错。

导入使用系统文件选择器，支持多选；blob / data 导出使用系统“另存为”，以 192 KiB 分块写入临时文件，避免整个大谱包转成一条巨大 JS 字符串。首版单次导出上限 512 MiB，建议逐首导出，低内存设备仍可能失败。不需要全部文件访问权限。尚未在安卓真机上验证 SAF 文件选择/保存。

## 显示与性能

默认 sensorLandscape 横屏、隐藏状态栏/导航栏、前台常亮、WebView 硬件加速。系统手势或输入键盘可能暂时显示系统栏，部分新系统的大屏设备可能覆盖方向限制。切后台暂停预览并触发保存，回到应用需要手动继续播放。

不修改仓库中的网页源文件，Android 本地服务仅在返回文件时为当前网页版本适配：默认 60 FPS、平板横屏布局、关闭预览实时频谱、关闭在线背景，Canvas 像素比上限 1.5。已有保存设置优先，用户仍可在网页设置调整 FPS 和特效。这会降低高清屏的画面锐度；不保证所有机型无卡顿。依赖网页当前脚本结构，后续站点重构需要重新检查这些适配。音频仍使用 Web Audio，不是原生低延迟引擎，不能保证机台级音画延迟。

## 构建与签名

用 Android Studio 打开本目录，JDK 17、Android SDK 35、Gradle 8.7、AGP 8.6.1；也可用本机 Gradle 执行 gradle assembleDebug。发布签名通过环境变量 DC_KEYSTORE（绝对路径）、DC_KEY_PASSWORD_FILE（密码文件绝对路径）提供，别名 dancecube；执行 gradle assembleRelease。禁止将签名私钥和密码推到公开仓库。

首次交付 APK 使用独立预览版密钥，v1/v2/v3 签名。持续更新同一应用需保留同一个密钥并增加 versionCode。备份包 signing-backup 仅供维护者保存；对外分享 APK 即可。

## 验证与限制

已验证 Java 编译、DEX 生成、APK manifest、zipalign 与 v1/v2/v3 签名；桌面 JVM 测试验证早期脚本注入、60 FPS 默认值、背景默认关闭、Worker MIME、音频 Range、无效 Range、目录穿越阻止、导出脚本加载。没有 Android 模拟器或实机，未确认首次下载、应用内存储、文件导入导出、触屏编辑、全屏、切后台和复杂秀谱的实际帧率，需真机回归后再作为稳定发行。

卸载请在系统应用管理中卸载；应用内下载站点及歌曲缓存会随之删除，先导出谱包。APK 卸载不删除此前通过系统另存为导出的文件。
